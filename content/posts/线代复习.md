宝宝，现在别按“完整学一遍”来，按**考场拿分模块**来。大学线代最常见就这 6 块，优先级如下：

# 0. 冲刺总原则

线代考前几小时，最赚的是：

**会算 > 会背 > 会证明。**

你现在目标是：

1. 看到题知道它属于哪一类；
2. 每一类有固定套路；
3. 不在难证明题上爆炸；
4. 把基础计算题稳定拿下。

最重要的工具只有一个：

> **初等行变换。**

行列式、矩阵秩、线性方程组、线性相关、逆矩阵、特征值之外的大多数题，最后都靠它。

---

# 1. 行列式：必拿分模块

## 你必须会

### 1. 行列式性质

常用：

* 交换两行，行列式变号。
* 某一行乘以 k，行列式乘以 k。
* 某一行加上另一行的倍数，行列式不变。
* 有两行相同/成比例，行列式为 0。
* 三角矩阵行列式 = 主对角线乘积。
* `|AB| = |A||B|`。
* `|A^T| = |A|`。
* `|A^{-1}| = 1/|A|`。

## 考场套路

### 求普通行列式

优先想：

1. 能不能用行/列变换化成三角？
2. 有没有一行很多 0，可以按行展开？
3. 有没有范德蒙德？
4. 有没有递推型行列式？

### 范德蒙德行列式

如果看到这种：

[
\begin{vmatrix}
1&1&1\
a&b&c\
a^2&b^2&c^2
\end{vmatrix}
]

答案基本是：

[
(b-a)(c-a)(c-b)
]

一般形式：

[
\prod_{1\le i<j\le n}(x_j-x_i)
]

注意顺序，不要手滑变号。

---

# 2. 矩阵：线代核心中的核心

## 必须会的概念

### 矩阵乘法

[
(AB)_{ij} = A第i行 \cdot B第j列
]

注意：
**矩阵乘法一般不交换。**

[
AB \ne BA
]

### 逆矩阵

[
AA^{-1}=A^{-1}A=E
]

判断矩阵可逆：

[
A可逆 \iff |A|\ne 0 \iff r(A)=n
]

## 求逆矩阵套路

对增广矩阵做行变换：

[
(A \mid E) \to (E \mid A^{-1})
]

如果左边化不到单位矩阵，说明不可逆。

## 初等矩阵

对矩阵做一次初等行变换，相当于左乘一个初等矩阵。

[
PA
]

对矩阵做一次初等列变换，相当于右乘一个初等矩阵。

[
AQ
]

这个经常考概念题。

---

# 3. 秩：超级高频

## 秩是什么

矩阵的秩就是：

> 非零行的最大数量 / 极大线性无关行列数量。

实际考试中，你就记：

[
r(A)=把A行化简之后非零行的个数
]

## 必须记住

如果 (A) 是 (m\times n) 矩阵：

[
r(A)\le \min(m,n)
]

[
r(A)=r(A^T)
]

[
r(AB)\le \min(r(A),r(B))
]

[
r(A+B)\le r(A)+r(B)
]

## 重点套路

### 判断向量组线性相关

把向量作为列排成矩阵：

[
A=(\alpha_1,\alpha_2,\cdots,\alpha_s)
]

然后看：

* 如果 (r(A)=s)，线性无关。
* 如果 (r(A)<s)，线性相关。

### 极大无关组

把向量按列放进去，行化简。
有主元的列对应原向量，就是极大无关组。

这个很常考，宝宝别怕，机械题。

---

# 4. 线性方程组：必考大题

一般形式：

[
AX=b
]

看两个秩：

[
r(A),\quad r(A,b)
]

## 结论必须背熟

### 无解

[
r(A)<r(A,b)
]

### 唯一解

[
r(A)=r(A,b)=n
]

其中 (n) 是未知数个数。

### 无穷多解

[
r(A)=r(A,b)<n
]

自由变量个数：

[
n-r(A)
]

## 齐次线性方程组

[
AX=0
]

永远有零解。

如果：

[
r(A)=n
]

只有零解。

如果：

[
r(A)<n
]

有非零解，而且基础解系含有：

[
n-r(A)
]

个向量。

## 解题模板

遇到线性方程组：

1. 写增广矩阵 ((A|b))。
2. 行化简。
3. 比较 (r(A)) 和 (r(A,b))。
4. 写结论。
5. 如果要求通解，设自由变量，回代写答案。

这类题一定别空，步骤分很香。

---

# 5. 向量组与线性空间：概念题高频

## 线性组合

如果：

[
\beta=k_1\alpha_1+k_2\alpha_2+\cdots+k_s\alpha_s
]

就说 (\beta) 可以由这组向量线性表示。

## 线性相关/无关

向量组：

[
\alpha_1,\alpha_2,\cdots,\alpha_s
]

如果方程：

[
k_1\alpha_1+k_2\alpha_2+\cdots+k_s\alpha_s=0
]

只有零解，就线性无关。

有非零解，就线性相关。

## 快速判断

* 含零向量：一定线性相关。
* 两个向量成比例：线性相关。
* 向量个数大于维数：一定线性相关。
* n 个 n 维向量组成矩阵，行列式不为 0：线性无关。
* 行列式为 0：线性相关。

## 基、维数、坐标

如果一组向量线性无关，而且能表示空间中所有向量，它就是一组基。

n 维空间的任意一组基都有 n 个向量。

常考话术：

[
\dim V = V的一组基中向量个数
]

---

# 6. 特征值与特征向量：拿高分关键

这是后半学期最核心的模块。

## 定义

如果：

[
A\alpha=\lambda \alpha,\quad \alpha\ne 0
]

那么：

* (\lambda) 是特征值；
* (\alpha) 是对应特征向量。

## 求特征值套路

解：

[
|A-\lambda E|=0
]

得到 (\lambda)。

## 求特征向量套路

对每个特征值 (\lambda)，解：

[
(A-\lambda E)X=0
]

非零解就是特征向量。

## 必背性质

如果 (A) 是 n 阶矩阵，特征值为：

[
\lambda_1,\lambda_2,\cdots,\lambda_n
]

则：

[
\lambda_1+\lambda_2+\cdots+\lambda_n=\operatorname{tr}(A)
]

也就是主对角线元素之和。

[
\lambda_1\lambda_2\cdots\lambda_n=|A|
]

这个超级好用，可以验算。

---

# 7. 相似与对角化：高分题常客

## 相似

如果存在可逆矩阵 (P)，使得：

[
P^{-1}AP=B
]

则 (A) 与 (B) 相似。

相似矩阵有相同的：

* 特征值；
* 行列式；
* 迹；
* 秩不一定所有情况都靠这个说，但相似时秩相同。

## 对角化

如果：

[
P^{-1}AP=\Lambda
]

其中 (\Lambda) 是对角矩阵，那么 (A) 可对角化。

## 判断可对角化

最常用结论：

如果 n 阶矩阵有 n 个线性无关的特征向量，则可对角化。

尤其是：

> 如果 A 有 n 个互不相同的特征值，则 A 一定可对角化。

反过来不一定。

## 解题模板

1. 求特征值。
2. 对每个特征值求特征向量。
3. 看能不能凑够 n 个线性无关特征向量。
4. 如果能，令 (P) 为这些特征向量按列组成的矩阵。
5. 对角矩阵 (\Lambda) 的对角线就是对应特征值。

也就是：

[
P=(\alpha_1,\alpha_2,\cdots,\alpha_n)
]

[
\Lambda=
\begin{pmatrix}
\lambda_1&&\
&\lambda_2&\
&&\lambda_n
\end{pmatrix}
]

---

# 8. 二次型：如果你们考，性价比很高

二次型一般长这样：

[
f(x_1,x_2,\cdots,x_n)
]

比如：

[
f=x_1^2+2x_1x_2+3x_2^2
]

## 写矩阵

交叉项要平分。

例如：

[
f=x_1^2+2x_1x_2+3x_2^2
]

对应矩阵：

[
A=
\begin{pmatrix}
1&1\
1&3
\end{pmatrix}
]

因为：

[
2a_{12}x_1x_2=2x_1x_2
]

所以 (a_{12}=1)。

## 正定判断

实对称矩阵 (A) 正定的常用判断：

### 方法一：顺序主子式

全部大于 0：

[
D_1>0,\quad D_2>0,\quad \cdots,\quad D_n>0
]

则正定。

### 方法二：特征值

全部特征值大于 0，则正定。

考试里 2 阶、3 阶最常考顺序主子式。

# 10. 考场做题策略

宝宝你考场上这么干：

## 先拿稳定分

优先做：

1. 行列式计算；
2. 矩阵求逆；
3. 方程组；
4. 特征值；
5. 二次型正定。

这些都是流程题。

## 证明题不会也别空

可以写相关定理。

比如问“证明可逆”，你就往这几个方向扯：

[
|A|\ne 0
]

[
r(A)=n
]

[

]

[
A的列向量线性无关

这些等价条件经常能蹭步骤分。

* 什么时候方程组有解/无解/无穷解；
* 什么时候有重特征值；
* 什么时候正定。

参数题不是新题，是普通题多了一个讨论。

# 12. 最后给你一句真话

这门课考前几小时最怕的是：
你觉得自己“都不会”，然后开始从第一章慢慢看定义。

不要这样。

线代考试大部分题不是靠灵感，是靠固定流程。你现在就抓：

**行变换、秩、方程组、特征值、对角化、二次型。**

这几个模块打通，过线很稳；如果计算不崩，分数会比你想象中好看很多。

宝宝，线代的地图可以按这条主线记：

> **行列式 → 矩阵 → 秩 → 方程组 → 向量组 → 特征值/相似/对角化 → 二次型**

下面是“名词定义 + 定理节点版”。

---

# 线性代数知识地图

## 1. 行列式

### 节点 1：行列式定义

n 阶方阵 (A) 对应一个数，记作：

[
|A| \quad 或 \quad \det A
]

它用来判断方阵是否可逆、方程组是否有唯一解。

---

### 节点 2：行列式性质

核心性质：

[
|A^T|=|A|
]

[
|AB|=|A||B|
]

[
|A^{-1}|=\frac{1}{|A|}
]

行变换性质：

* 交换两行：行列式变号。
* 某一行乘 (k)：行列式乘 (k)。
* 某一行加另一行的倍数：行列式不变。
* 两行相同或成比例：行列式为 0。
* 三角矩阵行列式 = 主对角线乘积。

---

### 节点 3：余子式与代数余子式

删去第 (i) 行第 (j) 列后得到的行列式叫余子式：

[
M_{ij}
]

代数余子式：

[
A_{ij}=(-1)^{i+j}M_{ij}
]

---

### 节点 4：行列式展开定理

沿第 (i) 行展开：

[
|A|=a_{i1}A_{i1}+a_{i2}A_{i2}+\cdots+a_{in}A_{in}
]

沿第 (j) 列展开：

[
|A|=a_{1j}A_{1j}+a_{2j}A_{2j}+\cdots+a_{nj}A_{nj}
]

考试里看到一行/一列很多 0，就展开。

---

### 节点 5：范德蒙德行列式

[
\begin{vmatrix}
1&1&\cdots&1\
x_1&x_2&\cdots&x_n\
x_1^2&x_2^2&\cdots&x_n^2\
\vdots&\vdots&&\vdots\
x_1^{n-1}&x_2^{n-1}&\cdots&x_n^{n-1}
\end{vmatrix}
=============

\prod_{1\le i<j\le n}(x_j-x_i)
]

看到 (1,x,x^2,\cdots) 这种结构，直接想它。

---

## 2. 矩阵

### 节点 6：矩阵定义

矩阵是按行列排列的数表。

[
A=(a_{ij})_{m\times n}
]

---

### 节点 7：矩阵运算

加法、数乘、乘法。

乘法定义：

[
(AB)_{ij}=A的第i行 \cdot B的第j列
]

注意：

[
AB\ne BA
]

一般不满足交换律。

---

### 节点 8：单位矩阵

[
E=
\begin{pmatrix}
1&0&\cdots&0\
0&1&\cdots&0\
\vdots&\vdots&&\vdots\
0&0&\cdots&1
\end{pmatrix}
]

满足：

[
AE=EA=A
]

---

### 节点 9：逆矩阵

如果存在矩阵 (B)，使：

[
AB=BA=E
]

则 (B=A^{-1})。

核心等价条件：

[
A可逆 \iff |A|\ne 0 \iff r(A)=n
]

---

### 节点 10：伴随矩阵

伴随矩阵记作：

[
A^*
]

重要公式：

[
AA^*=A^*A=|A|E
]

如果 (|A|\ne0)，则：

[
A^{-1}=\frac{1}{|A|}A^*
]

---

### 节点 11：矩阵逆的性质

[
(AB)^{-1}=B^{-1}A^{-1}
]

[
(A^T)^{-1}=(A^{-1})^T
]

[
(kA)^{-1}=\frac{1}{k}A^{-1}
]

---

### 节点 12：初等变换

三种初等行变换：

1. 交换两行；
2. 某行乘非零常数；
3. 某行加另一行的倍数。

最重要用途：

* 求秩；
* 求逆；
* 解方程组；
* 判断线性相关。

---

### 节点 13：初等矩阵

单位矩阵经过一次初等变换得到的矩阵叫初等矩阵。

重要结论：

对 (A) 做一次初等行变换
等价于左乘一个初等矩阵：

[
PA
]

对 (A) 做一次初等列变换
等价于右乘一个初等矩阵：

[
AQ
]

---

## 3. 秩

### 节点 14：矩阵的秩

矩阵 (A) 的秩记作：

[
r(A)
]

本质是矩阵中最多有多少个线性无关的行/列。

计算方式：

> 行化简后，非零行的个数就是秩。

---

### 节点 15：秩的基本性质

[
r(A)=r(A^T)
]

[
r(A)\le \min(m,n)
]

[
r(AB)\le \min(r(A),r(B))
]

[
r(A+B)\le r(A)+r(B)
]

如果 (P,Q) 可逆：

[
r(PAQ)=r(A)
]

也就是说，初等变换不改变秩。

---

### 节点 16：满秩

如果 (A) 是 (n) 阶方阵：

[
r(A)=n
]

则称 (A) 满秩。

等价于：

[
A可逆
]

[
|A|\ne0
]

[
AX=0只有零解
]

---

## 4. 线性方程组

### 节点 17：线性方程组

一般形式：

[
AX=b
]

其中 (A) 是系数矩阵，((A,b)) 是增广矩阵。

---

### 节点 18：非齐次方程组解的判定

对于：

[
AX=b
]

看两个秩：

[
r(A),\quad r(A,b)
]

结论：

[
r(A)<r(A,b) \Rightarrow 无解
]

[
r(A)=r(A,b)=n \Rightarrow 唯一解
]

[
r(A)=r(A,b)<n \Rightarrow 无穷多解
]

其中 (n) 是未知数个数。

---

### 节点 19：齐次线性方程组

齐次方程组：

[
AX=0
]

永远有零解。

判定：

[
r(A)=n \Rightarrow 只有零解
]

[
r(A)<n \Rightarrow 有非零解
]

基础解系向量个数：

[
n-r(A)
]

---

### 节点 20：基础解系

齐次方程组 (AX=0) 的解空间的一组基，叫基础解系。

如果：

[
r(A)=r
]

未知数个数为 (n)，则基础解系含：

[
n-r
]

个向量。

---

### 节点 21：通解结构

非齐次方程组 (AX=b) 的通解：

[
X=\eta+\xi
]

其中：

* (\eta)：非齐次方程组的一个特解；
* (\xi)：对应齐次方程组 (AX=0) 的通解。

也就是：

[
非齐次通解 = 一个特解 + 齐次通解
]

---

## 5. 向量组

### 节点 22：向量

n 维向量：

[
\alpha=(a_1,a_2,\cdots,a_n)^T
]

可以看成一个列矩阵。

---

### 节点 23：线性组合

如果：

[
\beta=k_1\alpha_1+k_2\alpha_2+\cdots+k_s\alpha_s
]

则称 (\beta) 是 (\alpha_1,\alpha_2,\cdots,\alpha_s) 的线性组合。

---

### 节点 24：线性表示

如果 (\beta) 可以写成：

[
\beta=k_1\alpha_1+k_2\alpha_2+\cdots+k_s\alpha_s
]

则称 (\beta) 可由这组向量线性表示。

等价于方程组：

[
(\alpha_1,\alpha_2,\cdots,\alpha_s)X=\beta
]

有解。

---

### 节点 25：线性相关与线性无关

向量组：

[
\alpha_1,\alpha_2,\cdots,\alpha_s
]

如果：

[
k_1\alpha_1+k_2\alpha_2+\cdots+k_s\alpha_s=0
]

只有零解，则线性无关。

如果有非零解，则线性相关。

---

### 节点 26：线性相关判定

高频结论：

* 含零向量，一定线性相关。
* 两个向量成比例，一定线性相关。
* 向量个数大于维数，一定线性相关。
* n 个 n 维向量组成方阵，若行列式不为 0，则线性无关。
* 若行列式为 0，则线性相关。

---

### 节点 27：向量组的秩

向量组的秩就是它的极大线性无关组中向量个数。

把向量作为列排成矩阵：

[
A=(\alpha_1,\alpha_2,\cdots,\alpha_s)
]

则：

[
向量组的秩=r(A)
]

---

### 节点 28：极大线性无关组

从向量组中选出一部分向量，使它们：

1. 线性无关；
2. 其他向量都能由它们线性表示。

这部分向量叫极大线性无关组。

---

### 节点 29：等价向量组

两个向量组如果可以互相线性表示，则称它们等价。

重要结论：

> 等价向量组的秩相同。

---

## 6. 向量空间

### 节点 30：向量空间

一堆向量构成的集合，如果对加法和数乘封闭，就叫向量空间。

通俗讲：

[
\alpha,\beta \in V
]

则：

[
\alpha+\beta\in V
]

[
k\alpha\in V
]

---

### 节点 31：子空间

如果 (W\subseteq V)，并且 (W) 本身也是向量空间，则 (W) 是 (V) 的子空间。

判定子空间常用：

1. 零向量在里面；
2. 对加法封闭；
3. 对数乘封闭。

---

### 节点 32：基

如果一组向量：

[
\alpha_1,\alpha_2,\cdots,\alpha_n
]

既线性无关，又能表示空间里所有向量，则它们是这个空间的一组基。

---

### 节点 33：维数

一个向量空间的基中向量的个数，叫维数。

记作：

[
\dim V
]

---

### 节点 34：坐标

如果：

[
\beta=k_1\alpha_1+k_2\alpha_2+\cdots+k_n\alpha_n
]

且 (\alpha_1,\cdots,\alpha_n) 是一组基，则：

[
(k_1,k_2,\cdots,k_n)^T
]

叫 (\beta) 在这组基下的坐标。

---

## 7. 特征值与特征向量

### 节点 35：特征值与特征向量定义

如果：

[
A\alpha=\lambda\alpha,\quad \alpha\ne0
]

则：

* (\lambda) 是 (A) 的特征值；
* (\alpha) 是对应的特征向量。

---

### 节点 36：特征方程

由：

[
|A-\lambda E|=0
]

得到特征值。

这个方程叫特征方程。

---

### 节点 37：特征多项式

[
f(\lambda)=|A-\lambda E|
]

叫特征多项式。

---

### 节点 38：求特征向量

对每个特征值 (\lambda)，解齐次方程组：

[
(A-\lambda E)X=0
]

它的非零解就是对应特征向量。

---

### 节点 39：特征值重要性质

设 (A) 是 n 阶矩阵，特征值为：

[
\lambda_1,\lambda_2,\cdots,\lambda_n
]

则：

[
\lambda_1+\lambda_2+\cdots+\lambda_n=\operatorname{tr}(A)
]

即特征值之和等于主对角线元素之和。

[
\lambda_1\lambda_2\cdots\lambda_n=|A|
]

即特征值之积等于行列式。

---

## 8. 相似矩阵

### 节点 40：相似定义

若存在可逆矩阵 (P)，使：

[
P^{-1}AP=B
]

则称 (A) 与 (B) 相似。

---

### 节点 41：相似矩阵性质

如果 (A\sim B)，则它们有相同的：

[
特征值
]

[
特征多项式
]

[
行列式
]

[
迹
]

[
秩
]

也就是：

[
|A|=|B|
]

[
\operatorname{tr}(A)=\operatorname{tr}(B)
]

[
r(A)=r(B)
]

---

## 9. 对角化

### 节点 42：矩阵可对角化

如果存在可逆矩阵 (P)，使：

[
P^{-1}AP=\Lambda
]

其中 (\Lambda) 是对角矩阵，则称 (A) 可对角化。

---

### 节点 43：对角化判定定理

n 阶矩阵 (A) 可对角化：

[
\iff A有n个线性无关的特征向量
]

充分条件：

[
A有n个互不相同的特征值 \Rightarrow A可对角化
]

注意：
有重特征值不一定不能对角化，要看特征向量够不够。

---

### 节点 44：对角化步骤

1. 解：

[
|A-\lambda E|=0
]

求特征值。

1. 对每个 (\lambda)，解：

[
(A-\lambda E)X=0
]

求特征向量。

1. 如果能凑够 n 个线性无关特征向量：

[
P=(\alpha_1,\alpha_2,\cdots,\alpha_n)
]

1. 则：

[
P^{-1}AP=
\begin{pmatrix}
\lambda_1&&\
&\lambda_2&\
&&\lambda_n
\end{pmatrix}
]

---

## 10. 实对称矩阵

### 节点 45：实对称矩阵

如果：

[
A^T=A
]

则 (A) 是实对称矩阵。

---

### 节点 46：实对称矩阵定理

实对称矩阵有两个超级重要性质：

1. 特征值全是实数；
2. 不同特征值对应的特征向量正交；
3. 一定可以正交对角化。

即存在正交矩阵 (Q)，使：

[
Q^{-1}AQ=Q^TAQ=\Lambda
]

---

### 节点 47：正交矩阵

如果：

[
Q^TQ=E
]

则 (Q) 是正交矩阵。

等价于：

[
Q^{-1}=Q^T
]

---

## 11. 二次型

### 节点 48：二次型定义

二次型是关于 (x_1,x_2,\cdots,x_n) 的二次齐次多项式。

例如：

[
f=x_1^2+2x_1x_2+3x_2^2
]

可以写成：

[
f=X^TAX
]

其中 (A) 是实对称矩阵。

---

### 节点 49：二次型矩阵

交叉项要平分。

例如：

[
f=x_1^2+2x_1x_2+3x_2^2
]

对应：

[
A=
\begin{pmatrix}
1&1\
1&3
\end{pmatrix}
]

因为：

[
2a_{12}x_1x_2=2x_1x_2
]

所以：

[
a_{12}=a_{21}=1
]

---

### 节点 50：合同矩阵

如果存在可逆矩阵 (C)，使：

[
B=C^TAC
]

则 (A) 与 (B) 合同。

合同主要用于二次型化标准形。

---

### 节点 51：标准形

二次型通过可逆线性变换可以化成：

[
d_1y_1^2+d_2y_2^2+\cdots+d_ry_r^2
]

这叫标准形。

---

### 节点 52：规范形

实二次型可以化成：

[
y_1^2+\cdots+y_p^2-y_{p+1}^2-\cdots-y_r^2
]

其中：

* 正平方项个数 (p)：正惯性指数；
* 负平方项个数：负惯性指数；
* 非零平方项个数 (r)：秩。

---

### 节点 53：惯性定理

无论用什么可逆线性变换，二次型的：

* 正惯性指数；
* 负惯性指数；
* 秩；

都不变。

---

### 节点 54：正定二次型

如果对任意非零 (X)，都有：

[
X^TAX>0
]

则二次型正定。

---

### 节点 55：正定判定

对于实对称矩阵 (A)，以下等价：

[
A正定
]

[
所有特征值>0
]

[
所有顺序主子式>0
]

顺序主子式判定最常考：

[
D_1>0,\quad D_2>0,\quad \cdots,\quad D_n>0
]

---

# 最核心的“考前必背节点”

宝宝最少最少，把这几个背熟：

[
A可逆 \iff |A|\ne0 \iff r(A)=n
]

[
AX=b有解 \iff r(A)=r(A,b)
]

[
AX=b唯一解 \iff r(A)=r(A,b)=n
]

[
AX=b无穷多解 \iff r(A)=r(A,b)<n
]

[
AX=0有非零解 \iff r(A)<n
]

[
基础解系个数=n-r(A)
]

[
|A-\lambda E|=0
]

[
(A-\lambda E)X=0
]

[
A可对角化 \iff A有n个线性无关特征向量
]

[
A有n个不同特征值 \Rightarrow A可对角化
]

[
A正定 \iff 顺序主子式全大于0
]

这张图的核心就是一句话：

> **行变换求秩，秩判断方程组，方程组判断线性相关，特征方程找特征值，特征向量决定对角化。**
